1. Introduce the motivation: keyword search misses semantic matches in research-paper discovery.
2. Show the data pipeline: arXiv API download, normalization, JSONL cache, Pinecone ingestion.
3. Explain the Pinecone data model: index, namespace, record ID, embedded text, generated vector, metadata.
4. Launch Streamlit and show database status.
5. Search for: "Efficient techniques for running large language models on devices with limited memory."
6. Apply a category or year filter and explain how metadata filtering combines with vector search.
7. Open a result abstract and follow the arXiv link.
8. Use "Find similar papers" on one result.
9. Show the evaluation script outputs and explain which metrics are proxy metrics versus human judgments.
10. Close with limitations and future work.
